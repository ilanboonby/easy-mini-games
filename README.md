# TLS Quest

Mini-jeu interactif (français) pour comprendre TLS : clés publique/privée, Diffie-Hellman, certificats, handshake et attaque de l'homme du milieu.

**Jouer** : ouvrir `index.html` dans un navigateur (aucune dépendance, aucun build). La progression est sauvegardée dans le navigateur.

Les prochains concepts sont listés dans [ROADMAP.md](ROADMAP.md).
