# Roadmap

## Fait
Les 23 jeux de la première feuille de route sont terminés (voir README), regroupés par thème dans le menu : cryptographie, réseau, applications web, identité et accès, logiciel et données, cryptographie avancée, détection et réponse.

## Idées pour la suite
| Concept | Idée de gameplay |
|---------|------------------|
| Sécurité des conteneurs et du cloud | Un nuage mal configuré : stockage public, droits trop larges, images vulnérables |
| Sécurité des API | Autorisation au niveau des objets (BOLA), limitation de débit, validation des entrées |
| Sécurité mobile | Stockage local, communications, permissions, jetons sur un téléphone perdu |
| Cryptographie appliquée : mauvais usages | Réutilisation de nonce, mauvais mode, comparaison non constante, aléa prévisible |
| Vie privée et anonymisation | Réidentification, k-anonymat, confidentialité différentielle |
| Sécurité de l'IA | Injection de prompt, empoisonnement de données, fuite via les sorties d'un modèle |
| Forensique numérique | Reconstituer une chronologie à partir d'images disque et de journaux |

## Idées transverses
- Sauvegarde de progression partagée entre les jeux, avec un « passeport » de badges
- Mode « révision » avec fiches mémo de tous les carnets
- Version anglaise
- Auto-hébergement du hub et export du carnet en PDF
